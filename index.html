      자동화
      
      
      
      
      Data · Report데이터 · 보고 자동화
      • 광고 원본 데이터 자동 적재Google Ads Script · Meta API
        매일 아침 내려받아 붙여넣던 광고별 성과를 시트에 자동으로 쌓습니다. 빠진 날짜는 다음 실행 때 채웁니다.
      • 광고 현황 보고 생성기Node.js
        집행 중 캠페인의 소진율·CPA·이전 기수 비교·예상 DB를 보고 양식 문장으로 뽑습니다. 사람은 대응 방향만 씁니다.
      • GA4 랜딩 퍼널 리포트Apps Script · GA4 API
        랜딩별 조회 → 신청 시도 → 신청 완료를 나란히 비교해, GA를 몰라도 먼저 고칠 랜딩을 고를 수 있게 했습니다.
      • 랜딩 성과 카드크롬 확장
        랜딩 페이지를 열면 그 자리에 신청률, 같은 유형 평균 대비, 매체별 신청률이 뜹니다.
      • 광고 데이터 지도HTML
        캠페인 이름 → 매체 세팅 → UTM → GA4·픽셀 → 시트 → 보고 화면이 어떻게 이어지는지 한 장으로 그렸습니다.
      Setup · QA세팅 · 검수
      • 디맨드젠 캠페인 자동 입력크롬 확장
        캠페인·광고그룹·광고 이름, 영상, 제목, 설명, UTM까지 차례로 입력하고 게시 버튼 앞에서 멈춥니다. 최종 확인은 사람이 합니다.
      • 소재 영상 일괄 업로드크롬 확장 · YouTube API
        영상 여러 개를 정한 순서대로 유튜브에 올리고, 구글 광고 등록용 작업 파일까지 만듭니다.
      • 광고 이름 규칙 검사크롬 확장
        메타·구글 관리자 화면에서 규칙에 어긋난 광고 이름에 빨간 밑줄과 이유를 표시해, 매체 간 성과 비교가 어긋나지 않게 합니다.
      • 표 복사 + 지표 계산크롬 확장
        광고 관리자·GA4 표를 엑셀로 복사하면서 CTR·CPC·CPA 칸을 붙이고, 평균에서 크게 벗어난 행을 표시합니다.
      Creative · Reference소재 · 레퍼런스
      • 경쟁 광고 자동 관찰크롬 확장 · Whisper
        경쟁 광고주의 집행 중 광고를 6시간마다 기록하고, 28일 이상 살아남은 영상은 자동으로 받아씁니다.
      • 영상 첫 8초 후킹 추출Whisper · OCR
        광고 영상 앞 8초의 첫마디와 화면 자막을 뽑아, 오래 집행된 순으로 후킹 모음을 만듭니다.
      • 디자인 레퍼런스 보관함크롬 확장
        랜딩·상세페이지를 저장하면 전체 캡처·문구·가격·색을 남기고, 다시 저장하면 바뀐 가격과 문구를 비교합니다.
      • 숏츠 성과 수집기Node.js · YouTube API
        경쟁 채널·키워드에서 조회수가 높게 나온 숏츠를 뽑아 표로 저장합니다.
      • 투명성센터 → 유튜브 버튼북마클릿
        구글 광고 투명성센터의 경쟁사 영상 광고를 클릭 한 번으로 원본 유튜브에서 엽니다.
      • 광고 대본 기획 스킬Claude Skill
        레퍼런스 영상을 줄 단위로 받아써 우리 상품으로 바꿔 쓰고, 첫 문장 유형과 헤드카피 문법을 적용합니다.
